## 🚀 Getting Started Locally

### 1. Clone the repository
```bash
git clone https://github.com/VEDANTraj9/Portfolio-website.git
cd Portfolio-website
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## 📦 How to Deploy (Step-by-Step)

### Option 1: Deploy to Vercel (Recommended for Next.js)

1. **Push your code to GitHub:**
   ```bash
   git add .
   git commit -m "feat: upgrade portfolio with high-voltage thor theme"
   git branch -M main
   git remote add origin https://github.com/VEDANTraj9/Portfolio-website.git
   git push -u origin main
   ```
2. Go to **[vercel.com](https://vercel.com/)** and log in with GitHub.
3. Click **"Add New Project"** and import your `Portfolio-website` repository.
4. Keep the default settings (Framework: Next.js) and click **"Deploy"**.
5. Your portfolio is live with instant SSL and automatic deployments on every `git push`!

---

### Option 2: Deploy to Netlify

1. Go to **[netlify.com](https://netlify.com/)** and log in.
2. Click **"Add new site"** -> **"Import an existing project"** -> **"GitHub"**.
3. Select your repository `Portfolio-website`.
4. Build settings:
   - **Build Command:** `npm run build`
   - **Publish directory:** `.next`
5. Click **"Deploy site"**.
